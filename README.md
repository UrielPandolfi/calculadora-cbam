# Coldwell Banker · Franquicias

Exportación completa del sitio: código fuente, imágenes, calculadora, generación de PDF, esquema de datos y archivos originales de referencia.

## Descargar y ejecutar

1. Descarga `coldwell-franquicias-calculadora.zip` y descomprímelo.
2. Consulta `EXPORTACION.md` para instalar dependencias y configurar el entorno.
3. Usa Node.js >= 22.13 y la versión de pnpm indicada en `package.json`.

El ZIP contiene 128 archivos y conserva la estructura original del proyecto, incluidos los archivos de configuración. No incluye credenciales, datos de prospectos ni dependencias instaladas.

Esta entrega conserva la versión final del sitio, incluido el skyline de Santa Fe, el texto de coaching empresarial 1 a 1 y el logotipo en el PDF.

La carga mediante el navegador se entrega como un archivo ZIP completo; los archivos fuente se encuentran dentro de ese archivo.
